# 🌤️ Weather App

A sleek, responsive, and real-time **Weather Application** built to deliver accurate weather information with an intuitive user interface. It provides current weather conditions, temperature, humidity, wind speed, and location-based forecasts.

---

## ✨ Features

* 🌍 **Real-Time Weather Updates**: Fetch live weather data for any city worldwide.
* 📍 **Auto-Location Detection**: Automatically detect and show local weather conditions.
* 🌡️ **Comprehensive Details**: Displays temperature, humidity, wind speed, and weather descriptions.
* 📱 **Fully Responsive**: Optimized for seamless viewing across mobile, tablet, and desktop screens.
* 🎨 **Dynamic Visuals**: Theme and background adjustments based on day/night or weather conditions.

---

## 🛠️ Tech Stack

* **Frontend**: HTML5, CSS3, JavaScript (ES6+)
* **Styling**: Modern CSS3 (Flexbox/Grid, Glassmorphic UI)
* **API**: OpenWeatherMap API (or direct Weather API integration)
* **Icons**: FontAwesome / Weather Icons

---

## ⚙️ How to Run Locally

*Clone the repository:*

git clone [https://github.com/PakizaNasir/Weather-App.git](https://github.com/PakizaNasir/Weather-App.git)

*Navigate to the project directory:*

cd Weather-App

*Open the application:*

Simply double-click index.html or use Live Server in VS Code to run it locally.

---

## 🗝️ API Configuration

If using OpenWeatherMap API:

Register at OpenWeatherMap and get your free API key.

Open script.js and replace the placeholder API key with your own:

JavaScript
const API_KEY = "YOUR_API_KEY_HERE";
